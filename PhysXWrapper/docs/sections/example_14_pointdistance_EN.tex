\subsection{Description}
\textbf{Point distance queries} find the closest point on a shape to a given query point. Use cases: proximity sensors, magnetic attraction, AI navigation.

\subsubsection{Math: GJK Algorithm}
Distance between convex shapes using support functions:
\begin{equation}
d(\mathbf{A}, \mathbf{B}) = \min_{\mathbf{p} \in \mathbf{A}, \mathbf{q} \in \mathbf{B}} |\mathbf{p} - \mathbf{q}|
\end{equation}
