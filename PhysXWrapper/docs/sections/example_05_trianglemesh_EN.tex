\subsection{Functional Description}

\subsubsection{What is a Triangle Mesh?}

A \textbf{triangle mesh} is PhysX's representation of static, non-convex collision geometry. Unlike convex meshes, triangle meshes can represent arbitrary shapes including terrains, buildings, and complex environment geometry.

\textbf{Key Characteristics:}
\begin{itemize}
    \item \textbf{Static Only:} Triangle meshes can only be used with \texttt{PxRigidStatic} actors
    \item \textbf{Non-Convex:} Can represent concave shapes (caves, overhangs, etc.)
    \item \textbf{Acceleration Structure:} Uses BVH (Bounding Volume Hierarchy) for fast queries
    \item \textbf{Large Scale:} Optimized for millions of triangles (entire game levels)
\end{itemize}

\textbf{Use Cases:}
\begin{itemize}
    \item \textbf{Terrain:} Height-mapped or arbitrary terrain surfaces
    \item \textbf{Buildings:} Static environment architecture
    \item \textbf{Level Geometry:} Non-moving world collision
    \item \textbf{Large Objects:} Complex static props (bridges, trees, etc.)
\end{itemize}

\subsubsection{Physics and Mathematical Concepts}

\paragraph{Bounding Volume Hierarchy (BVH)}

A BVH is a tree structure that hierarchically partitions space to accelerate collision queries:

\begin{equation}
\text{BVH} = \{\text{Root}, \text{InternalNodes}, \text{LeafNodes}\}
\end{equation}

Where:
\begin{itemize}
    \item \textbf{Root:} Bounding box containing entire mesh
    \item \textbf{Internal Nodes:} Axis-aligned bounding boxes (AABBs) subdividing space
    \item \textbf{Leaf Nodes:} Small groups of triangles (primitives)
\end{itemize}

\paragraph{BVH Construction Process}

The construction follows a top-down recursive partitioning:

\begin{enumerate}
    \item \textbf{Initialization:} Compute bounding box of all triangles
    \item \textbf{Splitting:} Choose split axis (longest extent or SAH heuristic)
    \item \textbf{Partitioning:} Divide triangles into left and right children
    \item \textbf{Recursion:} Repeat for children until leaf size reached
\end{enumerate}

Time complexity: $O(n \log n)$ for $n$ triangles (balanced tree).

\paragraph{Surface Area Heuristic (SAH)}

PhysX uses SAH to optimize BVH quality. The cost function for a split:

\begin{equation}
\text{Cost}(s) = c_t + \frac{SA_L}{SA_P} \cdot N_L \cdot c_i + \frac{SA_R}{SA_P} \cdot N_R \cdot c_i
\end{equation}

Where:
\begin{itemize}
    \item $c_t$ = traversal cost
    \item $c_i$ = intersection cost
    \item $SA_L, SA_R$ = surface area of left/right children
    \item $SA_P$ = surface area of parent
    \item $N_L, N_R$ = number of triangles in left/right
\end{itemize}

This heuristic minimizes expected ray-box intersection cost.

\paragraph{BVH33 vs BVH34}

PhysX provides two midphase algorithms:

\begin{table}[h]
\centering
\begin{tabular}{|l|p{6cm}|p{6cm}|}
\hline
\textbf{Aspect} & \textbf{BVH33} & \textbf{BVH34} \\
\hline
Node Size & 3x3 = 9 AABBs per node & 3x4 = 12 AABBs per node \\
\hline
Traversal & Ternary tree (3 children) & Quaternary tree (4 children) \\
\hline
Cache Efficiency & Good & Better (more compact) \\
\hline
Build Time & Moderate & Slightly slower \\
\hline
Query Performance & Fast & Slightly faster (fewer cache misses) \\
\hline
Mesh Size & Moderate & Slightly smaller \\
\hline
Best For & General purpose & Large scenes, modern CPUs \\
\hline
\end{tabular}
\caption{BVH33 vs BVH34 Comparison}
\end{table}

\paragraph{Triangle-Ray Intersection}

The Möller-Trumbore algorithm is used for ray-triangle tests:

\begin{equation}
\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}
\end{equation}

Intersection with triangle $(\mathbf{v}_0, \mathbf{v}_1, \mathbf{v}_2)$:

\begin{equation}
\mathbf{o} + t\mathbf{d} = (1-u-v)\mathbf{v}_0 + u\mathbf{v}_1 + v\mathbf{v}_2
\end{equation}

Where $(u, v)$ are barycentric coordinates and $t$ is distance. Valid intersection requires:
\begin{equation}
u \geq 0, \quad v \geq 0, \quad u+v \leq 1, \quad t \geq 0
\end{equation}

\subsubsection{Cooking Pipeline}

The triangle mesh cooking pipeline consists of:

\begin{equation}
\text{Mesh Data} \xrightarrow{\text{Validate}} \text{Valid Data} \xrightarrow{\text{Preprocess}} \text{Clean Data} \xrightarrow{\text{Build BVH}} \text{PxTriangleMesh}
\end{equation}

\textbf{Preprocessing Steps:}
\begin{enumerate}
    \item \textbf{Welding:} Merge duplicate vertices within tolerance
    \item \textbf{Cleaning:} Remove degenerate triangles (zero area, invalid normals)
    \item \textbf{Edge Computation:} Identify active (convex) edges for contact generation
    \item \textbf{BVH Construction:} Build spatial acceleration structure
    \item \textbf{Serialization:} Convert to binary format (optional)
\end{enumerate}

\subsection{Code Comparison: Original vs Wrapper}

\subsubsection{Architecture Overview}

\textbf{Original PhysX Approach:}
\begin{itemize}
    \item Two separate functions: \texttt{createBV33TriangleMesh} and \texttt{createBV34TriangleMesh}
    \item Boolean flags for configuration (5-6 parameters per function)
    \item Direct \texttt{PxCookTriangleMesh} and \texttt{PxCreateTriangleMesh} calls
    \item Manual time measurement with \texttt{SnippetUtils}
    \item Printf-based result reporting
    \item Global variables for PhysX instances
\end{itemize}

\textbf{PhysXWrapper Approach:}
\begin{itemize}
    \item Unified \texttt{TriangleMeshBuilder} class handling both BVH33 and BVH34
    \item Configuration via \texttt{TriangleMeshConfig} struct with enum for midphase
    \item Result encapsulation in \texttt{TriangleMeshResult} struct
    \item Built-in validation and comprehensive error handling
    \item Extended functionality: terrain/plane generators
    \item Modern C++ design with RAII and structured returns
\end{itemize}

\subsubsection{Side-by-Side Comparison: BVH Creation}

\textbf{Original PhysX (BVH33 Function):}
\begin{lstlisting}[caption={Original: Separate BVH33 cooking function}]
void createBV33TriangleMesh(
    PxU32 numVertices, const PxVec3* vertices,
    PxU32 numTriangles, const PxU32* indices,
    bool skipMeshCleanup, bool skipEdgeData, bool inserted,
    bool cookingPerformance, bool meshSizePerfTradeoff)
{
    PxU64 startTime = SnippetUtils::getCurrentTimeCounterValue();

    // Setup descriptor
    PxTriangleMeshDesc meshDesc;
    meshDesc.points.count = numVertices;
    meshDesc.points.data = vertices;
    meshDesc.points.stride = sizeof(PxVec3);
    meshDesc.triangles.count = numTriangles;
    meshDesc.triangles.data = indices;
    meshDesc.triangles.stride = 3 * sizeof(PxU32);

    // Setup cooking params
    PxTolerancesScale scale;
    PxCookingParams params(scale);

    // Configure BVH33 midphase
    params.midphaseDesc = PxMeshMidPhase::eBVH33;

    // Setup common cooking params
    setupCommonCookingParams(params, skipMeshCleanup, skipEdgeData);

    // Configure cooking hint
    if (cookingPerformance)
        params.midphaseDesc.mBVH33Desc.meshCookingHint =
            PxMeshCookingHint::eCOOKING_PERFORMANCE;
    else
        params.midphaseDesc.mBVH33Desc.meshCookingHint =
            PxMeshCookingHint::eSIM_PERFORMANCE;

    // Configure size/perf tradeoff
    if(meshSizePerfTradeoff)
        params.midphaseDesc.mBVH33Desc.meshSizePerformanceTradeOff = 0.0f;
    else
        params.midphaseDesc.mBVH33Desc.meshSizePerformanceTradeOff = 0.55f;

    // Cook mesh
    PxTriangleMesh* triMesh = NULL;
    PxU32 meshSize = 0;

    if (inserted) {
        triMesh = PxCreateTriangleMesh(params, meshDesc,
                    gPhysics->getPhysicsInsertionCallback());
    } else {
        PxDefaultMemoryOutputStream outBuffer;
        PxCookTriangleMesh(params, meshDesc, outBuffer);
        PxDefaultMemoryInputData stream(outBuffer.getData(),
                                         outBuffer.getSize());
        triMesh = gPhysics->createTriangleMesh(stream);
        meshSize = outBuffer.getSize();
    }

    // Print results
    PxU64 stopTime = SnippetUtils::getCurrentTimeCounterValue();
    float elapsedTime =
        SnippetUtils::getElapsedTimeInMilliseconds(stopTime - startTime);
    printf("\t Create triangle mesh with %d triangles: \n",numTriangles);
    printf("\t Elapsed time in ms: %f \n", double(elapsedTime));

    triMesh->release();
}
\end{lstlisting}

\textbf{PhysXWrapper (Unified Approach):}
\begin{lstlisting}[caption={Wrapper: Unified triangle mesh cooking}]
TriangleMeshResult TriangleMeshBuilder::cookTriangleMesh(
    const PxVec3* vertices, PxU32 numVertices,
    const PxU32* indices, PxU32 numTriangles,
    const TriangleMeshConfig& config,
    PxOutputStream* stream)
{
    TriangleMeshResult result;

    // Comprehensive validation
    if (!m_physics) {
        result.success = false;
        result.error = "PhysX not initialized";
        m_lastError = result.error;
        return result;
    }

    if (!validateMeshData(vertices, numVertices, indices, numTriangles)) {
        result.success = false;
        result.error = "Invalid mesh data";
        m_lastError = result.error;
        return result;
    }

    // Setup descriptor
    PxTriangleMeshDesc meshDesc;
    meshDesc.points.count = numVertices;
    meshDesc.points.data = vertices;
    meshDesc.points.stride = sizeof(PxVec3);
    meshDesc.triangles.count = numTriangles;
    meshDesc.triangles.data = indices;
    meshDesc.triangles.stride = 3 * sizeof(PxU32);

    // Create cooking params from config
    PxCookingParams cookingParams = createCookingParams(config);

    // Configure midphase based on config
    if (config.midphase == TriangleMeshMidphase::BVH33) {
        cookingParams.midphaseDesc = PxMeshMidPhase::eBVH33;

        // BVH33 specific settings
        if (config.cookingPerformance)
            cookingParams.midphaseDesc.mBVH33Desc.meshCookingHint =
                PxMeshCookingHint::eCOOKING_PERFORMANCE;
        else
            cookingParams.midphaseDesc.mBVH33Desc.meshCookingHint =
                PxMeshCookingHint::eSIM_PERFORMANCE;

        cookingParams.midphaseDesc.mBVH33Desc.meshSizePerformanceTradeOff =
            config.meshSizePerformanceTradeoff;

    } else { // BVH34
        cookingParams.midphaseDesc = PxMeshMidPhase::eBVH34;

        // BVH34 specific settings
        cookingParams.midphaseDesc.mBVH34Desc.numPrimsPerLeaf =
            config.numTrisPerLeaf;
    }

    // Configure preprocessing flags
    if (!config.cleanMesh)
        cookingParams.meshPreprocessParams |=
            PxMeshPreprocessingFlag::eDISABLE_CLEAN_MESH;

    if (!config.precomputeActiveEdges)
        cookingParams.meshPreprocessParams |=
            PxMeshPreprocessingFlag::eDISABLE_ACTIVE_EDGES_PRECOMPUTE;

    // Start high-resolution timing
    auto startTime = std::chrono::high_resolution_clock::now();

    PxTriangleMesh* triMesh = nullptr;

    // Cook mesh based on configuration
    if (stream) {
        // Cook to external stream
        bool cookResult = PxCookTriangleMesh(cookingParams, meshDesc,
                                              *stream);
        if (!cookResult) {
            result.success = false;
            result.error = "Failed to cook triangle mesh to stream";
            m_lastError = result.error;
            return result;
        }
        result.success = true;

    } else if (config.directInsertion) {
        // Direct insertion (fastest for runtime)
        triMesh = PxCreateTriangleMesh(cookingParams, meshDesc,
                    m_physics->getPhysicsInsertionCallback());
        if (!triMesh) {
            result.success = false;
            result.error = "Failed to create triangle mesh";
            m_lastError = result.error;
            return result;
        }

        result.mesh = triMesh;
        result.numVertices = triMesh->getNbVertices();
        result.numTriangles = triMesh->getNbTriangles();
        result.success = true;

    } else {
        // Serialize then create (for offline cooking)
        PxDefaultMemoryOutputStream outStream;
        bool cookResult = PxCookTriangleMesh(cookingParams, meshDesc,
                                              outStream);
        if (!cookResult) {
            result.success = false;
            result.error = "Failed to cook triangle mesh";
            m_lastError = result.error;
            return result;
        }

        result.meshSize = outStream.getSize();

        PxDefaultMemoryInputData inStream(outStream.getData(),
                                          outStream.getSize());
        triMesh = m_physics->createTriangleMesh(inStream);
        if (!triMesh) {
            result.success = false;
            result.error = "Failed to create mesh from cooked data";
            m_lastError = result.error;
            return result;
        }

        result.mesh = triMesh;
        result.numVertices = triMesh->getNbVertices();
        result.numTriangles = triMesh->getNbTriangles();
        result.success = true;
    }

    // End timing
    auto endTime = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::microseconds>(
                        endTime - startTime);
    result.cookingTime = duration.count() / 1000.0f; // to ms

    m_lastError.clear();
    return result;
}
\end{lstlisting}

\paragraph{Terrain Generation}

\begin{lstlisting}[caption={Terrain generation method}]
TriangleMeshResult TriangleMeshBuilder::createTerrain(
    const PxVec3& origin,
    PxU32 numRows, PxU32 numCols,
    PxReal cellSizeRow, PxReal cellSizeCol,
    PxReal heightScale,
    const TriangleMeshConfig& config)
{
    // Calculate grid dimensions
    PxU32 numX = numCols + 1;
    PxU32 numZ = numRows + 1;
    PxU32 numVertices = numX * numZ;
    PxU32 numTriangles = numRows * numCols * 2;

    // Generate vertices with random heights
    std::vector<PxVec3> vertices(numVertices);
    PxU32 currentIdx = 0;
    for (PxU32 i = 0; i <= numRows; i++) {
        for (PxU32 j = 0; j <= numCols; j++) {
            PxReal x = origin.x + j * cellSizeRow;
            PxReal z = origin.z + i * cellSizeCol;
            PxReal y = origin.y + heightScale *
                       (2.0f * (float(rand()) / float(RAND_MAX)) - 1.0f);
            vertices[currentIdx++] = PxVec3(x, y, z);
        }
    }

    // Generate triangle indices (two triangles per grid cell)
    std::vector<PxU32> indices(numTriangles * 3);
    currentIdx = 0;
    for (PxU32 i = 0; i < numRows; i++) {
        for (PxU32 j = 0; j < numCols; j++) {
            PxU32 base = i * numX + j;

            // Triangle 1
            indices[currentIdx++] = base + 1;
            indices[currentIdx++] = base;
            indices[currentIdx++] = base + numX;

            // Triangle 2
            indices[currentIdx++] = base + numX + 1;
            indices[currentIdx++] = base + 1;
            indices[currentIdx++] = base + numX;
        }
    }

    return createTriangleMesh(vertices, indices, config);
}
\end{lstlisting}

\subsection{Usage Methodology}

\subsubsection{Usage Pattern 1: Terrain for Gameplay}

\begin{lstlisting}[caption={Creating runtime terrain}]
PhysXCore physics;
physics.initialize(PhysXCoreConfig());

TriangleMeshBuilder builder(physics.getPhysics());

// Use runtime config for fast cooking
TriangleMeshConfig config = TriangleMeshBuilder::getRuntimeConfig();

// Generate 64x64 terrain with 3m height variation
TriangleMeshResult result = builder.createTerrain(
    PxVec3(-32.0f, 0.0f, -32.0f),  // Origin
    64, 64,                         // 64x64 grid
    1.0f, 1.0f,                     // 1m cell size
    3.0f,                           // 3m height variation
    config
);

if (result.success) {
    std::cout << "Terrain cooked in " << result.cookingTime << " ms\n";
    std::cout << result.numTriangles << " triangles\n";

    // Create static actor with terrain
    PxTriangleMeshGeometry geom(result.mesh);
    PxRigidStatic* terrain =
        physics.getPhysics()->createRigidStatic(PxTransform(PxIdentity));
    PxShape* shape = physics.getPhysics()->createShape(
        geom, *physics.getDefaultMaterial());
    terrain->attachShape(*shape);
    physics.getScene()->addActor(*terrain);
    shape->release();
}
\end{lstlisting}

\subsubsection{Usage Pattern 2: Offline Terrain Pre-cooking}

\begin{lstlisting}[caption={Offline cooking with file export}]
// Offline high-quality cooking
TriangleMeshConfig offlineConfig =
    TriangleMeshBuilder::getOfflineConfig();

// Cook to stream
PxDefaultMemoryOutputStream stream;
TriangleMeshResult cookResult = builder.createTriangleMeshToStream(
    vertices, indices, stream, offlineConfig
);

if (cookResult.success) {
    // Save to file
    std::ofstream file("terrain.cooked", std::ios::binary);
    file.write((const char*)stream.getData(), stream.getSize());
    file.close();
}

// Later, at runtime:
std::ifstream file("terrain.cooked", std::ios::binary | std::ios::ate);
size_t fileSize = file.tellg();
file.seekg(0);
std::vector<char> buffer(fileSize);
file.read(buffer.data(), fileSize);

PxDefaultMemoryInputData inStream(
    reinterpret_cast<PxU8*>(buffer.data()),
    static_cast<PxU32>(fileSize));
PxTriangleMesh* mesh = builder.loadTriangleMeshFromStream(inStream);
\end{lstlisting}
