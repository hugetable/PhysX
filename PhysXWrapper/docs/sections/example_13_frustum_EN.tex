\subsection{Description}
\textbf{Frustum queries} find objects within a camera view frustum for culling invisible objects. Essential for rendering optimization.

\subsubsection{Math: Frustum Planes}
View frustum defined by 6 planes:
\begin{equation}
\text{Frustum} = \{\text{Near}, \text{Far}, \text{Left}, \text{Right}, \text{Top}, \text{Bottom}\}
\end{equation}

\subsection{Core API}
\begin{lstlisting}
class FrustumQuery {
public:
    std::vector<PxActor*> queryFrustum(
        PxScene* scene, const FrustumPlanes& frustum);
};
